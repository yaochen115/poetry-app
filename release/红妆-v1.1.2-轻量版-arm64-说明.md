# 红妆 v1.1.2 arm64 轻量版

内部版本号 9，发布日期 2026-11-07。

安装包 `红妆-v1.1.2-轻量版-arm64.apk`，仅支持 arm64-v8a 的安卓设备，最低 Android 10。

文件大小 20,041,629 字节，约 19.11 MiB。相比 v1.1.1 通用包缩小 61.8%。沿用旧包的包名和签名，支持从 v1.1.1 覆盖安装。黑夜模式及现有内容随包提供，选择、收藏和熟练度采用原有本地存储。

已核验 ZIP 完整性、包名、版本号、签名、仅含 arm64 原生库，以及所有 Flutter 资源与 v1.1.1 一致。现有业务代码沿用 v1.1.1 已通过的 8 项测试和静态分析结果，本轮验证重点为架构打包。尚未真机安装测试。

构建命令 `./scripts/workspace_build.ps1 -Action apk -TargetPlatform android-arm64`。脚本仍支持默认通用构建，arm64 构建时 Gradle 额外过滤依赖库中的其他架构文件。

数据版本 1.2.33，字典版本 1.1.24。可用原文 1555 篇，可读译文 816 篇，缺译文 739 篇；字典 2956 字、1884 词。内容待补校项延续上一版本。

旧通用包独立保留。源码数据备份见同目录带版本号 ZIP；SHA256 见同目录 manifest。修改前构建配置备份位于 `expansion/checkpoints/pre-lite-v1.1.2.zip`。
