# 红妆 v1.1.3 arm64 轻量版

内部版本号 10，更新日期 2026-11-07。

“我的”页面的黑夜模式改为固定在右下角的 21px 小图标，点击在明暗模式间切换。浅色模式显示月亮，深色模式显示太阳，设置仍自动保存。图标采用标准按钮点击区域，支持辅助功能提示。

沿用 arm64 轻量版构建，最低 Android 10。大小 19,910,741 字节，约 18.99 MiB。8项Flutter测试、静态分析、安装包版本/架构/签名/ZIP及数据资源一致性核验通过；尚未真机测试。旧版本和修改前源码保留。

构建命令 `./scripts/workspace_build.ps1 -Action apk -TargetPlatform android-arm64`。本轮界面修改位于 `app/lib/pages/me_page.dart`，对应回归测试为 `app/test/night_mode_test.dart`，修改前备份为 `expansion/checkpoints/pre-theme-icon-v1.1.3.zip`。

版本化源码数据备份及 SHA256 清单放在本目录。词库仍采用 poems 1.2.33 / dict 1.1.24，原有内容待补校事项见上一版本交接文档。
