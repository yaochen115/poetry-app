# 下载资料批量转换 v1.0.0

负责人本次已授权制作脚本、试跑转换；未授权自动改变名单、采用抽查标准或将未审资料正式入库。正式数据与APK没有变化。

脚本：`scripts/convert_downloaded_materials_v1_0_0.py`，复用现有Python、OpenCC与入库格式，不下载工具，不调用模型或付费接口，不创建智能体。

## 功能

读取已下载的JSON数组、items对象或JSONL；支持chinese-gushiwen的writer/remark/translation，以及poetry-source的authorName/annotation/translation。清洗HTML、合并段落、提取正文词注、过滤合法标签。原文和作者按繁简及标点归一匹配，题名差异标为待核对；不会改动正式原文、ID。

也识别paragraph/translate字段，但无作者的数据需要先建立可靠身份映射，不仅凭诗句自动认领。

本脚本处理已下载文件，不承担全站爬取。字段转换和结构检查无法证明全文无漏译、释义正确或具有转载许可。

## 第一步：批量转换

在项目根目录、已配置Python的终端中执行：

```powershell
python -B scripts/convert_downloaded_materials_v1_0_0.py prepare --source expansion/sources/chinese-gushiwen/guwen --source expansion/sources/poetry-source/source --output expansion/working/download-conversion-v1.0.0
```

当前机器Python不在PATH，可把命令开头的`python`替换为：

```powershell
& 'C:/Users/22946/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
```

输出两份JSON：

- `candidates-v1.0.0.json`：最优参考候选、来源文件及行号/SHA256、原文输入哈希、问题、未匹配ID和缺字清单。候选只代表待审资料。
- `reviews-template-v1.0.0.json`：默认pending的审核模板。复制为新的带版本审核文件后编辑，不覆盖原模板。

每次变更输入或清洗规则请使用新的版本输出目录；已有输出内容不同时拒绝覆盖。

首次实跑：扫描18620条记录，594篇待补中匹配330篇；20篇未触发当前结构问题。作者不一致或无作者不会自动认领，所以与此前宽口径的353篇参考候选不同。没有发生正式入库。

缺标签是问题之一，不能用随意标签凑齐。审核时可在该条审核记录加入合法的`tags`数组；脚本会按其所属类别枚举验证。

## 第二步：内容与资料使用审核

模板中每篇默认：decision=pending、sourceUse=unconfirmed。实际核对后才填写：

```json
{
  "id": "实际ID",
  "candidateHash": "保留模板中的完整哈希",
  "decision": "approved",
  "sourceUse": "approved",
  "reviewer": "实际审核者",
  "explanation": "实际执行的内容核对及来源使用依据",
  "tags": ["该类别的合法标签"]
}
```

保留模板顶层poems数组与dictionary对象。未获批准条目不输出。不能把结构检查直接当语义审核；不得为加快速度批量虚填上述字段。

若译文、注释需要修改，应形成新版本候选文件并重新计算candidateHash、复核，不能沿用旧审核哈希。缺注释或可疑译文不自动补造。

缺字释义文件为`{"字":{"meanings":["释义"],"ancient":["古义"]}}`；审核文件的dictionary对象中记录每字的decision=approved、reviewer和definitionHash。该哈希由脚本模块的digest函数对这条定义计算；缺定义或缺审核都会阻止组装。正式已存在释义优先，不覆盖。

## 第三步：生成现有程序可导入的批次

```powershell
python -B scripts/convert_downloaded_materials_v1_0_0.py assemble --candidates expansion/working/download-conversion-v1.0.0/candidates-v1.0.0.json --reviews 实际审核文件.json --dictionary 实际已审释义.json --data-version 1.2.9 --dictionary-version 1.1.20 --output expansion/enrichment/023.json
```

版本及批次023是当前暂停点的下一编号示例；正式操作前核对CURRENT_STATE和最新数据，避免版本倒退或覆盖。选中篇目没有缺字时可以省略--dictionary。

组装校验审核、候选哈希、来源SHA256、当前原文、结构、词注及缺字释义。生成patches/dictionaryAdditions及来源审核记录，**不会自行导入**。此批次兼容：

```powershell
python -B scripts/apply_enrichment_batch.py expansion/enrichment/023.json
python -B scripts/export_pending_enrichment.py
```

正式导入仍由现有工具完成备份、原所属批次同步、应用资源同步及审计回滚。上述导入命令本轮未执行。
