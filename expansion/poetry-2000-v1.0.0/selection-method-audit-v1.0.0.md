## 2. 必须先处理的实际问题

### P0：接口体裁不是可靠的硬分类依据

代码第15、94—96行把类型17“乐府诗”、70“楚辞”等直接放入诗类。实际结果：

| providerId | 输出 | 证据与影响 |
|---|---|---|
| 298429 | 温庭筠《忆江南 一》，诗 | 正文起“千万恨，恨极在天涯”，27个规范化汉字。 |
| 377817 | 温庭筠《梦江南·梦江南·千万恨》，词 | 与298429规范化全文完全相同，既错分体裁，又跨两类重复计数。 |
| 376655 | 屈原《卜居》，诗 | 起“屈原既放，三年不得复见”，为叙事问答文本；本地匹配同时带“古文观止”标签。不能因收入《楚辞》就自动充诗数。 |

建议：对来源类型建立“提示”而非硬通过规则；楚辞逐篇区分，骚体是否属于本任务另列口径，至少《卜居》应先移出诗候选。建立全局作品身份后再决定诗/词，不让同文在两类各计一次。不要反过来仅凭作者擅长词就全归词——现脚本 `ci_authors` 本身只加分，并没有直接按作者名字归词。

同样不能盲信本地分类标签：本地匹配给刘禹锡《竹枝词九首 二》（265601）带了“宋词三百首”标签，不能据此把其七言诗硬改成词。发生接口、选本标签、锚点体裁冲突时，应挂明确冲突状态，按作品本身及可靠底本核定。

### P0：锚点首句命中容许残篇、坏稿和错误篇章冒充经典

第92—106行：作者相同、首句在前160个规范化字符中出现，就可影响体裁并拿到锚点；第117行加10000分。没有篇章、完整性或讹字检查。

- 张若虚《春江花月夜》：255616为252字，334720只有147字、末止“斜月沉沉藏海雾”，仍同时匹配P020。完整性相差巨大，却各占一席。
- 岑参《白雪歌送武判官归京》：311489为126字，341890只有63字、末止“轮台东门送君去”，仍同时覆盖P054。
- 王勃《送杜少府之任蜀州》：336364含“海记忆体知己”的明显讹文，仍与正常的277713一起覆盖P021。这里应隔离坏稿，不能只称为近似异文。
- 《无衣》：377576的“岂曰无衣七兮”属《唐风》，377587的“岂曰无衣？与子同袍”属《秦风》。由于作者都为佚名、锚点首句只有“岂曰无衣”，二者都被算作秦风P005。**这是不同作品错误覆盖同一锚点，不是应该互相删除的重复诗。**

建议：锚点只负责检索，另设 `retrievalHit / identityConfirmed / textComplete / textIssue`。用规范题名或别题、诗经国风篇章、组诗序号及足够长的正文指纹确认身份；小序剥离后检查正文起点。4字或更短的首句须补第二句。只有身份明确且全篇完整的记录可计入最终覆盖；每个锚点记录一个选定版本，其余存候选。

### P1：当前去重不能实现“不同作品各计一首”

第110—112行按 `(规范作者,体裁,正文前6字)` 分桶，再用长度比>.88、相似度>.93合并，漏掉三类已出现的情况：

1. **合集＋单首重复。** 李绅356091《古风二首》与376833、376827两首《悯农》一起入选；王昌龄339399《出塞二首》与308656单首同选；韩愈349530《早春呈水部张十八员外二首》与376814《早春》同选。长短比低，所以阈值不会识别包含关系。应先拆组诗、记录父合集和成员关系，不能把合集额外算一首。
2. **首句变体漏检。** 王维307852、307853均题《使至塞上》，分别起“单车欲问边”“衔命辞天阙”，后三联相同。前6字不同，根本不会比较；即便取消此分桶，其相似度也只有.875，简单改阈值仍不够。应归同作异文候选并核定底本，不能独立占位。
3. **跨署名同文。** 王之涣259604《登鹳雀楼》与朱斌256252《登楼》全文相同；元稹268662《行宫》与王建262407《故行宫》全文相同。按作者分桶永不相遇。应保存归属冲突、一份规范作品及多个来源候选，不能借不同署名充成两首，也不能静默替作者定案。

建议先以全局规范化全文哈希找精确同文，再对同作者同题/别题、组诗成员、相同中后句做候选聚类。相似度只生成待核关系，不作为自动删除或“已校定异文”的依据。现有近似合并也只追加alternativeIds及anchorKeys，未保留结构化逐版本差异；本轮抽查未找到因合并实际丢失教材/选本标签的样例，故此处仅列潜在保留证据风险。

## 3. 排名、朝代修正与最终门槛

### P1：65是上限，不能误称“每位作者强制配65首”；但无依据补位确实严重

第122行名家加60分，第138行以后同分按作者、题名、providerId排；第143行设65首上限，经典锚点/唐宋三百首可豁免；第145行还会回填deferred，故65也不是最终硬上限。

快照中诗有6位、词有10位作者恰好65首。卢照邻入选65首全部弱依据；元稹65首中61首、卢纶65首中59首弱依据。词中李之仪65首有63首、张孝祥65首有61首、张先65首有60首弱依据。**达到上限证明不了这65首各自经典；674首词仅60分，实质靠作者名单和字面排序补位。**

另有“宽泛来源标签变相当经典”的问题：`ANTHO`含乐府、楚辞等类别，`classic`据此撤掉待知名度审核标记；仅有普通本地正文匹配也加200分。收录过或属于某大类，不等于通行名篇。上述弱依据比例因此还是偏宽松口径。

建议把“作品级教材/明确选本/编辑确认”与“仅作者知名/仅语料存在/体裁标签”拆开计分。60分作品留作候补，不能无条件补满；暂缺应明确报缺。先锁经典作品，再根据有作品依据的候选补时代与作者覆盖；作者上限仅作多样性约束。不要用调整65到另一个整数代替作品证据。

### P1：朝代按名字多数票，需有作者实体与冲突门槛

第59—69、126—128行用本地同名作者90%一致的朝代覆盖接口值，并保留providerValue与一条来源定位，这是可取的纠错记录。风险在于没有最小证据数、跨时代同名作者身份、时代别称归一或正文匹配前提；一条参考也可满足90%。名字相同不能证明是同一个作者。

建议按provider authorId建立显式身份映射，保留传署、佚名、合集署名等状态；跨时代或大跨度冲突先待核，不按名字覆盖。输出证据条数、朝代分布及对应作品，不只最后一条row。先统一汉末/魏晋、宋末元初等断代口径。本轮确认了198条修正的存在和部分正确实例，**未据此宣称198条逐一审核通过，也未凭疑似同名断言某条已误改。**

### P1：本地正文中的“一作”文字破坏选本匹配，已造成漏选

`normal()`只做HTML转文字、繁简及字符过滤，没有把正文内括注异文分离；第71—76行又先卡首6字、长度比及相似度。

李白《闻王昌龄左迁龙标遥有此寄》缓存310186已有28字正文，但本地正文末带“(随风 一作：随君)”，规范化后成34字。长度比28/34≈.824不达>.88，相似度≈.903不达>.91，于是本地“初中古诗”证据没有命中，作品未入这版名单。问题是匹配层未分离校记，不能通过给李白再加权解决。

建议来源分层提取“正文、序、题注、校记”并保存原始字段；仅清理已识别的校记格式，不全局删除括号。首6字只做快速索引，失败后按作者＋别题/正文指纹补检；疑似变体保留待核。不得通过重写诗泉原文让相似度变高。

### P1：`--final`门槛不足

第159行只要求2000条及锚点无缺；目前预览尚有锚点待补，现门槛会挡住当前稿，这一点有效。但将锚点补齐后，前述同文重复、合集重复、残篇、错体裁、词作者争议和无依据补位均不会自动阻止final。

建议最终再验：规范作品唯一数、每锚点合格版本映射、合集/成员无重复计数、体裁冲突为0或明确人工裁定、完整性异常为0、跨署名同文已有处理、弱依据候补未混入“已确认经典”。朝代覆盖按用户范围做缺口报告，尚缺时不能借错朝代或随机补位填数。

## 5. 给主进程的最小修正顺序与回归点

1. 先将明确讹文、残篇、体裁冲突隔离；修正温庭筠跨类别同文，剔除《卜居》自动进诗路径。
2. 为作品增加规范身份、组诗父子关系和版本候选；处理精确同文、跨署名、合集包含，再确认锚点。原始文本、providerId、缓存哈希及归属异说全部保留。
3. 分离本地校记/小序后重算作品级证据，补“已缓存却失去教材匹配”的条目；名家分和65上限不代替依据。
4. 再由教材、选本作品清单反推缺的候选池，主进程既有经典补齐工作可直接复用；最后重排与验证有效作品数，无需重新逐篇生成译注。

建议最少离线回归：①温庭筠同文只计词一次；②唐风、秦风《无衣》不互认锚点；③147字春江、63字白雪和“海记忆体知己”不能获合格锚点；④悯农合集不与两首同时计数；⑤同文异署不重复，署名冲突仍在；⑥末尾一作校记不阻止李白教材证据；⑦填满2000但含上述异常时final仍拒绝。相近阈值和前6字分桶只能做检索优化，不能替代这些作品层规则。
