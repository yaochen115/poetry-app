# 诗泉名单自动同步 v1.0.0

## 一条命令：下载、校验、自动入库

在项目根目录运行：

```powershell
& ./scripts/sync_poetry_api_v1_0_0.ps1
```

也可双击根目录 `一键同步诗泉-v1.0.0.cmd`。脚本直接写入本项目的 JSON 数据库 `data/poems.json`，同步 `app/assets/data/poems.json`；不创建另一个未接入 App 的空数据库，不构建 APK，不安装任何工具。

```powershell
# 已下载缓存直接入库，完全不联网
& ./scripts/sync_poetry_api_v1_0_0.ps1 -Offline
# 只预览，不改数据库
& ./scripts/sync_poetry_api_v1_0_0.ps1 -Preview
# 指定本次网络预算；下次运行同一命令复用已成功缓存
& ./scripts/sync_poetry_api_v1_0_0.ps1 -MaxRequests 2000 -Workers 2 -Interval 1
```

入口复用现有 Python；如需指定解释器，设置 `HONGZHUANG_PYTHON` 为现有 python.exe。没有使用 ExecutionPolicy Bypass。底层命令为 `python -B scripts/sync_poetry_api_v1_0_0.py --apply`。Python 入口默认预览，PowerShell/双击入口默认自动入库。

## 名单与匹配

- 输入固定为 `expansion/poetry-2000-v1.0.0/catalog-v1.0.2.json`：诗1000、词1000，220个经典锚点已列入，其中包含张若虚《春江花月夜》。这不是2000篇原文或译注均已取得的声明。
- 诗、词指历代作品，非限定唐代、宋代。名单按具体选本、学校来源标签、经典锚点和语料交叉选择。仅语料收录的扩展项保留知名度复核标记，不把名家所有作品都声称为经典。
- `matchingText` 是匹配参考，不当作诗泉下载正文。`content` 才是原文；源站未取得原文时留空。
- 实际接口是 `/api/search?q=...&page=1&pageSize=100&lang=zh-Hans`；原文缓存位于 `provider-api/cache`，每份文件有URL与SHA-256侧录。不要改用已验证返回404的 `/api/v1` 路由。
- 入库门槛：作者一致、规范化全文完全一致；规范化仅用于繁简、HTML转文字及标点匹配，不重写存储的诗泉原文。只首句相同、只有题名相同、残篇或相近异文均不自动通过。明确讹文和私用字形被隔离。异文可以在后续校勘阶段处理，不能降低门槛冒充已完成。
- 同文异署与现有库冲突时留待处理；已有同作者同文优先沿用已有ID与全部旧字段，避免学习记录丢失、覆盖旧译文或重复入库。停用ID不会被重新启用。

## 自动入库和版本保护

1. 校验名单计数、ID、正文指纹唯一性及缓存SHA。
2. 批量查询尚未严格匹配的原文，复用URL缓存，不逐篇人工下载。
3. 默认2个网络工作线程、全局至少1秒间隔；允许参数1–4线程、最小0.5秒。403/429/503等响应停止整个本次源站请求，不自动无限重试或绕过。网络预算到达后仍入库已通过的内容；其余下次续跑。
4. 合并已有记录，给真正新增作品分配稳定ID。`category` 的唐诗/宋词是兼容旧数据库的槽位，新增的 `genre` 才是实际诗/词体裁；App模型、分类入口、抽签与排版已支持这一差别，不把宋代诗人显示成唐代。
5. 入库前备份数据库与资源到 `expansion/checkpoints/pre-poetry-api-data-v版本--事务号`；新快照文件为 `data/versions/poems-v版本.json`。
6. 同步数据库和App资源后运行 `validate_data.py --original-only`；失败回滚两个文件。提交记录在 `expansion/poetry-api-imports/data-v版本-committed.json`。原文阶段通过不代表字典/译注完整验收。
7. 同内容重跑不增加记录、不重复分配ID、不增加数据版本。运行锁 `expansion/poetry-api-sync.lock` 防止同一脚本并行导入；异常退出残留锁时，先确认记录PID已不存在，再清理锁，不能盲删运行中的锁。

新原文明确保留 `original_only` 和译文、注释、主题标签、字典四项待补，不生成虚假译文或释义。本脚本不替代双站译注采集脚本。

## 继续推进

使用同一入口续采，无需再建下载脚本。先前6线程采集遇到503后已停止；本入口默认降为2线程并缓存续跑。待处理明细在 `expansion/poetry-api-sync-v1.0.0/run-v1.0.0--*.json` 的 `held` 中；来源改版、无结果和异文都不能自动计为成功。

原名录 `catalog-v1.0.1`、新名录 `v1.0.2`、原型 `selection-previews` 均保留；原型审核指出的问题不能当作已交付名单全部修复的证明。下一步仍需核查具体作品、原文完整性和组诗身份，再用两个网站的现成译注脚本补齐，不逐篇由AI翻译、不创建额外智能体。不要把 `catalog-v1.0.3` 中近似匹配的原文直接跳过严格同步器导入。
