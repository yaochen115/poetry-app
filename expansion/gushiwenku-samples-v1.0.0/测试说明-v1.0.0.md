## 采集方式和边界

- 脚本：scripts/probe_gushiwenku_v1_0_0.py。
- 只采集固定3篇；后两篇URL从首篇的公开链接发现，不扫描编号、不遍历站点。
- 请求串行间隔2秒、超时25秒、单页最多2MB；缓存复用，保存原始HTML、URL、时间、状态和SHA256。
- robots.txt实际获取HTTP200，内容为User-agent:*、Disallow:/template/。本次诗文路径未被禁止；这不代表现代译注内容的再分发授权。
- 普通网络执行被沙箱拒绝后，通过系统联网批准执行测试，没有绕过登录、验证码或访问限制。
