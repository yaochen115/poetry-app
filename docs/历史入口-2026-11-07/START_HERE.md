## 继续补译注的方法

不要重建诗词ID或再扩原文来代替补译注。参考 expansion/enrichment/010.json，选取未完成的原文，逐篇独立补全。下一份译注批次可命名011.json（译注批次与原文batches/编号分开）。只修改tags、translation和notes，原文与来源保留。

在项目根目录运行：

```text
python scripts/apply_enrichment_batch.py expansion/enrichment/011.json
python scripts/export_pending_enrichment.py
python scripts/prepare_expansion.py
python scripts/audit_expansion.py
```

apply_enrichment_batch.py会检查状态、补新字词、更新正式数据/应用资源/原文所属批次，校验失败会回滚，重复运行不追加。全部补全后才改editorialStatus为complete并清空pending，不能以“待补”文本冒充译文。

独立检查：

```text
python scripts/validate_data.py --original-only
python scripts/validate_data.py
```

第一条是当前原文阶段检查；第二条是完整验收，目前应该失败，因为3936条可用原文还没有译注与字典覆盖。
