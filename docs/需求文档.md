# 「红妆」诗词背诵软件 — 需求文档

- 文档版本：v1.0
- 建立日期：2026-11-02
- 状态：✅ 已与项目发起人逐项确认
- 关联文档：《技术方案》《数据规范》《进度日志》《交接文档》

## 1. 项目概述

### 1.1 基本信息

| 项目 | 内容 |
| --- | --- |
| 软件名称 | 红妆 |
| 平台 | Android 10（API 29）及以上 |
| 开发技术 | Flutter |
| 界面风格 | 纯奶白素色、极简、系统默认字体 |
| 应用图标 | 奶白底 + 朱砂红篆刻印章风格「红妆」二字（图标可使用红色，界面保持素色） |
| 使用方式 | 离线使用（全部数据内置，无需联网） |

### 1.2 软件定位

一款辅助个人背诵古诗词的安卓应用。收录唐诗、宋词、元曲及历代古文经典篇目，用户按照「未习 → 初习 → 熟习」逐步标记背诵进度，通过极简首页队列完成日常背诵，并在「我的」页随时检索、分类浏览、收藏与抽查复习。

### 1.3 核心使用流程

```
打开 App → 首页显示当前待背的一首诗词（全文阅读式背诵）
  → 长按字词查词典（字数内联释义+拼音）
  → 点击正文查看全文翻译（再点返回）
  → 打勾标记：未习（放回池中随机再现）/ 初习 / 熟习
  → 弹出「诗 / 词 / 曲 / 文」四选一 → 从该类未习中随机抽下一首
```

## 2. 功能需求

### FR-1 首页背诵队列（最高优先级）

- FR-1.1 首页只显示一首诗词正文与底部打勾小圆圈，不放任何其他元素（去「我的」页靠左右滑动，无图标按钮）。
- FR-1.2 未打勾前，每次打开 App 首页显示的诗词保持不变（状态持久化）。
- FR-1.3 打勾标记完成后，弹出弹层，仅含四个大字按钮 **诗 / 词 / 曲 / 文**（无标题、无说明小字、无类别计数），用户自选一类，再从该类**未习**的诗词中随机抽一首作为下一首显示。
- FR-1.4 若所选类别中已无未习诗词，提示该类已背完，并让用户选择其他类。
- FR-1.5 若全部类别均已无未习诗词，首页显示「全部背完」状态页（可继续从「我的」页复习抽查）。

### FR-2 掌握度标记（三档）

- FR-2.1 每首诗词拥有三档状态：**未习（默认）/ 初习 / 熟习**。
- FR-2.2 点击底部打勾小圆圈，圆钮上方弹出**带描边的小胶囊弹窗**（仅三个状态图标、无文字：空圈 / 半满 / 实心），选一个标记：
  - 未习 → 该诗放回诗词池，日后随机再现；
  - 初习 → 该诗从首页队列消失，不再复背（仅作为分类查看依据）；
  - 熟习 → 该诗从首页队列消失，不再复背（仅作为分类查看依据）。
- FR-2.3 状态可随时在背诵页、列表页、复习流程中更改，双向可逆（熟习也能改回未习）。
- FR-2.4 状态持久化保存在本机，卸载 App 前不丢失；更换/清除应用数据后重置。

### FR-3 背诵页（阅读页）

- FR-3.1 纯全文阅读模式：完整展示正文，无逐句揭晓、遮罩等机制，用户默背完成后自行打勾。
- FR-3.2 正文排版适合竖排手机单屏阅读，行距、字距、字号默认值清晰舒适；排版规则：**唐诗不缩进——绝句（四句）一句一行、律诗（八句）两句一行；词、元曲、古文每一行开头空两格**（详见 UI 规范）。
- FR-3.3 页面不设分页签：**点击正文即直接显示该诗的注释翻译，再次点击返回**（从首页进入时返回首页；从列表/复习等入口进入时先显示正文，点击切注释，再点返回原入口）。页内不设返回图标，仅靠点击正文/注释区域切换与返回。
- FR-3.4 页面含收藏按钮，可随时收藏/取消收藏。
- FR-3.5 长按正文中任意字或词，弹出该字词的词典卡（见 FR-4）。

### FR-4 长按查字典（内置离线字库）

- FR-4.1 长按正文中的字或词，弹出底部词典卡，展示：**读音（全拼，含多音字各读法）** 与 **该字在古汉语中的简要释义**。
- FR-4.2 字库覆盖诗词数据集中实际出现的**全部字**（均为内置离线数据，无需联网）。
- FR-4.3 长按词（相邻两字组成的词）时优先展示该词的释义；查不到词义时回退为逐字释义。
- FR-4.4 词典卡支持点击空白处关闭。
- FR-4.5 长按只弹出词典，不触发进入注释页或任何页面切换。

### FR-5 注释与翻译

- FR-5.1 每首内置全文现代化翻译（精简直白；长文仅译所选节选部分），**界面不展示重点注释**。
- FR-5.2 翻译在注释页整篇展示（点击正文进入；页内无「全文翻译」标题字样）。

### FR-6 查询（我的页入口名「查阅」，原名搜索）

- FR-6.1 支持按 **标题 / 作者 / 朝代与体裁 / 正文内容** 四种维度搜索（合并在一个搜索框，自动匹配全部维度）。结果直接列表展示，不显示「共 n 条结果」类计数。
- FR-6.2 搜索结果按相关度排序，展示标题、作者、体裁与掌握状态。
- FR-6.3 与分类浏览共用页面（见 FR-7）。

### FR-7 类目（我的页入口名「类目」，原名分类浏览）

- FR-7.1 页面直接列出全部篇目（按诗、词、曲、文顺序），**不设体裁/主题筛选标签**（标签分类机制已取消）。
- FR-7.2 列表项展示标题、作者、掌握状态。
- FR-7.3 点击列表项：该诗**直接成为首页当前诗词**（效果与打勾后随机抽中一致，含过渡效果），不进入阅读页。

### FR-8 典藏（我的页入口名「典藏」，原名收藏夹）

- FR-8.1 手动收藏喜欢的诗词，与掌握度标记相互独立。
- FR-8.2 收藏列表支持取消收藏；可按时间倒序展示。

### FR-9 「我的」页

- FR-9.1 顶部展示两个数字（标签「初习」「熟习」）：**初习（初习）数量** 与 **熟习（熟习）数量**，点击数字进入对应诗词列表。
- FR-9.2 页内四个入口卡片：**查阅**（原搜索）、**类目**（原分类浏览）、**典藏**（原收藏夹）、**省己**（原复习抽查）；无图标、无说明小字、文字居中。
- FR-9.3 不设底部页签：在 **首页（背）** 与 **我的** 之间**仅靠左右滑动**切换；底部仅保留极简圆点位置指示器；首页无任何图标入口。

### FR-10 省己（我的页入口名「省己」，原名复习抽查）

- FR-10.1 页面内掌握度三档：**未习 / 初习 / 熟习**；用户先自选一档，再点击居中按钮「**日省**」从该档随机抽一首打开背诵页。
- FR-10.2 点击「日省」后，抽中的诗**直接显示在首页**（效果与打勾后随机抽中一致），可在首页用小圆圈随时更改该诗掌握度。
- FR-10.3 抽查无遗忘曲线调度，纯手动随机。

## 3. 非功能需求

| 编号 | 要求 |
| --- | --- |
| NFR-1 | 完全离线可用，不依赖任何网络与第三方接口 |
| NFR-2 | 最低支持 Android 10，保证主流机型流畅运行 |
| NFR-3 | 界面主色调为纯奶白素色（见 UI 规范），避免彩色装饰 |
| NFR-4 | 正文使用系统默认字体（不做内置字体），保证渲染速度与包体 |
| NFR-5 | 冷启动 ≤ 2 秒（中端机参考值） |
| NFR-6 | 所有用户状态（掌握度、收藏、当前队列位置）本地持久化 |
| NFR-7 | 已入库数据：诗 / 词 / 曲 / 文各 50 首，共 200 首（v1.0.1）；扩充目标：各 1050 首共 4200 首（负责人 2026-11-03 已确认，待指令启动，见《交接文档》决策 29） |

## 4. UI 规范摘要

| 项 | 规范 |
| --- | --- |
| 主色调 | 奶白底（参考 #FBF8F3），卡片同色系浅奶白（#FFFFFF 或 #F7F2EA） |
| 文字 | 正文深墨灰（#2B2B2B），辅助文字浅墨灰，避免其他彩色 |
| 状态强调 | 三档掌握度用「未勾 / 半勾 / 实心勾」的**明暗深浅**区分（纯图标、无文字），而非彩色 |
| 字体 | 系统默认字体；首页正文 22~24sp、标题约 30sp，注释与列表 14~16sp |
| 布局 | 唐诗标题/作者/正文居中（行尾标点不计宽度）；词、曲、古文标题/作者/正文靠左、每行开头空两格；正文字号加大；我的页印章图标居中、四入口卡片居中；各子页大标题居中；首页与我的之间左右滑动切换，底部仅极简圆点指示器；唐诗一句/两句一行不缩进 |
| 图标 | 应用图标为白底朱砂红印章「红妆」；界面内图标一律单色墨灰 |
| 动效 | 克制，仅必要的页面切换与弹层过渡；左右滑动切换带轻量横向滑入动画 |

## 5. 验收标准

1. 安装 APK 后无网络可完整体验全部功能。
2. 首页首次显示一首未习诗词，杀进程重开仍是同一首。
3. 打勾「未习」后该诗可在后续随机中出现；打勾「部分/熟习」后不再出现在首页队列。
4. 打勾后四选一（诗/词/曲/文）→ 随机下一首，流程顺畅。
5. 长按任意正文文字均能弹出读音与释义；多音字展示正确读音。
6. 点击正文可直接查看全文翻译与关键注释，再次点击返回。
7. 搜索四种维度均能命中；分类浏览两级分类 + 掌握度筛选生效。
8. 「我的」页数字统计准确，点击进入对应列表。
9. 复习抽查：选掌握度 → 随机一首 → 可改掌握度。
10. 收藏/取消收藏即时生效并持久化。
