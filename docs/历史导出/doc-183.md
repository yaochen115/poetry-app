## 1. 技术选型

| 项 | 选型 | 说明 |
| --- | --- | --- |
| 开发框架 | Flutter（stable 渠道，Dart 3） | 单代码库产出安卓 APK，UI 表现力强 |
| 目标平台 | Android 10（API 29）及以上 | `minSdkVersion 29`，`targetSdkVersion` 取当前稳定最新 |
| 状态管理 | Provider（轻量） | 项目规模小，避免引入重量级框架 |
| 路由 | go_router 或 Navigator 2.0 简化方案 | 页面少，使用命名路由即可 |
| 本地持久化 | shared_preferences（状态）+ 内置资源文件（数据） | 掌握度、收藏、队列指针均为小键值数据；诗词与字库只读，打包为 assets |
| 数据格式 | JSON（assets 内置） | 见《数据规范》 |
| 无第三方网络依赖 | 是 | 全离线 |

## 4. 关键模块设计

### 4.1 首页队列（FR-1 / FR-2 核心）

- 状态保存三项：`currentPoemId`（当前显示的诗词）、`queuePointer`（无需顺序队列，因为下一首是"随机抽"）、`masteryMap`（每首诗状态）。
- 打勾流程状态机：`Idle → 三档选择（未掌握/部分/完全）→ 四选一（诗/词/曲/文）→ 从该类未掌握池随机抽取 → 回到 Idle`。
- 未掌握池 = 全部诗词中 `mastery != 已掌握 && 不在部分掌握` 且 **状态为未掌握** 的集合；「部分/完全掌握」的诗词被排除出首页池。
- 边界：某类无未掌握诗词时四选一按钮置灰并提示；全池为空时显示「全部背完」页。
- 状态持久化键名示例：`current_poem_id`、`mastery_<poemId>=0|1|2`（0 未掌握 / 1 部分 / 2 完全）。

### 4.2 长按查字典（FR-4）

- 正文使用 `RichText` + 每个字一个 `TextSpan`，每个 Span 挂 `GestureRecognizer`（长按触发；词级别查询按「当前字与相邻字组成的候选词」在词表中查找，命中则优先展示词义）。
- 长按弹出 `showModalBottomSheet` 词典卡：大字、全拼读音（含多音字多行）、古汉语简要释义（词义优先，否则字义）。
- 字库以 `Map<String (字), DictEntry>` 常驻内存，查询 O(1)；字库 JSON 约覆盖数千字，内存占用可控。

### 4.3 数据加载（性能）

- poems.json（200 首，目标 4200）启动时一次性加载；dict.json 惰性加载（首次进入背诵页时异步加载并缓存）。
- 数据只读，不存在写回；用户状态与数据分离。
- 内置数据版本号字段 `dataVersion`，便于后续扩充数据时迁移旧状态。

### 4.4 搜索（FR-6）

- 内存全文检索即可（数百至数千首规模无需倒排索引，4200 首目标在实测 APK 体积与启动耗时可接受范围内）：标题/作者/正文包含匹配 + 体裁标签匹配。
- 中文按子串匹配（`contains`），按匹配字段权重排序：标题 > 作者 > 正文。

### 4.5 主题与图标

- 主题：全局 `ThemeData` 奶白底（#FBF8F3 基准）、墨灰文字、控件单色。
- 应用图标：设计稿阶段产出「白底红印」图标多尺寸（`android/app/src/main/res/mipmap-*`）。

## 5. 构建与发布

| 项 | 方案 |
| --- | --- |
| 构建命令 | `flutter build apk --release` |
| 签名 | 首次交付用调试签名或生成自签名 keystore（个人使用，不上架商店）；安装时系统提示"未知来源"为正常现象 |

| 版本管理 | `语义化版本`，代码用 git 管理（待定是否初始化仓库，需与项目负责人确认） |

## 6. 测试计划（摘要）

- 单元测试：队列随机抽取不越界、三档状态迁移、四选一类池过滤。
- 手工验收：以《需求文档》第 5 节验收标准 1~10 条逐项过检。
- 真机测试：Android 10+ 真机安装验证冷启动、词典弹出、持久化。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 字库数据量大导致录入耗时 | 分批录入；字库按数据集实际用字扫描生成（脚本辅助），中文释义以常用义项为主 |
| 长按选词在 TextSpan 上的兼容性 | 项目启动后先做最小原型验证长按识别，再全量开发 |
| 数据扩充后旧状态丢失 | poems.json 带 `id` 稳定标识 + `dataVersion` 迁移策略 |
| Flutter 环境未安装 | 开发阶段前先检查/安装 Flutter SDK 与 Android 工具链（届时记录到进度日志） |
