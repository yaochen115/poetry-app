## 1. 一句话概括项目

「红妆」是一款纯离线、极简奶白风格的安卓诗词背诵应用：唐诗/宋词/元曲/古文内置背诵，三档掌握度标记，长按查古汉语字词典，含搜索、分类、收藏与随机抽查复习。

### 6.2 诗词库扩充流水线（200 → 4200 首，已验证可行）

**目标**：唐诗/宋词/元曲/古文各 1050 首（在现有各 50 首基础上各 +1000）。每首：权威原文（分段 `\n`）、全文翻译、3~18 条注释（term+meaning）、标签取自 `categories.json` 枚举、`excerptOf`/`excerptNote`（节选类古文必填）。

**步骤**（前一轮 100→200 扩充实测通过）：

1. **并行生成诗词 JSON**：多 agent 按体裁分批（每批约 50~100 首）生成符合《数据规范》的条目（id = 体裁前缀-序号，`tang-1000` 起 4 位；dynasty 约定：唐诗"唐"、宋词"宋"（李煜"五代·南唐"）、元曲"元"、古文"先秦·春秋/战国"、"西汉"、"三国·蜀"、"东晋"、"北魏"、"南朝·梁"、"唐"、"宋"、"明"、"清"）。
2. **合并校验**：Python 合并脚本去重（id 唯一、每类计数、字段非空、tags 合法、notes 3~18 条）。
3. **注音**：`pypinyin(heteronym=True, style=TONE3)` 为全部新增正文用字生成拼音。
4. **补字典**：扫描新增正文用字（`python scripts\validate_data.py --scan-chars`）→ 对 `dict.json` 缺失字并行 agent 分批补释义（拼音 TONE3 数组 + meanings + ancient），并从注释条目词头收割新双字词入 `words`（每批 ~47 字，输出 `_chars_out_N.json` 后合并）。
5. **校验必须全绿**：`python scripts\validate_data.py`（注意先更新脚本内常量：总数 200→4200、每类 50→1050、ID 正则 `\d{3}$`→`\d{3,4}$`）。**数据校验不过不许打包。**
6. **入库**：`data/*.json` → 拷贝到 `app/assets/data/` → 按 §4 同步构建 → 版本号 +0.0.1 → 新 APK 入 `release\`。
7. 递增 `dict.json` 的 `dataVersion`，并在《进度日志》记录本次扩充。

**已知规模参数**：APK 中 JSON 压缩率 17~22%；+4000 首预计数据体积约 3.2MB（APK 内），总包体 47.9→50.8MB 左右；生成耗时 5~7 小时。古文 1050 首超出传世名篇后，接受「知名度较低但真实存在的篇目」填充（负责人已知情）。

- 节选类古文（逍遥游、劝学、归去来兮辞、阿房宫赋、少年中国说等）的具体节选范围在数据录入阶段已定稿并标注于数据中。
- 生僻字读音（如元曲作者「白贲」贲读 bēn）录入时按权威字典标注，避免误读。
- **构建环境（务必全程 ASCII）**：Flutter SDK `D:\flutter`、Android SDK `D:\android-sdk`、JDK 17 `D:\jdk17\jdk-17.0.20.1+1`、构建目录 `D:\hz-app`。流程：`scripts\build_sync.ps1` 同步源码 → `scripts\build_apk.ps1` 构建并拷贝 APK。不要回到中文路径或 JDK 26（见决策 21）。
- **接手 AI 环境适配**：Claude Code 权限系统会拒绝 `powershell -ExecutionPolicy Bypass`；直接用 PowerShell 工具逐条执行 §4 的等价命令（robocopy 退出码 0~7 均正常）。flutter 必须用 `D:\flutter\bin\flutter.bat` 全路径调用，且不要用管道接它的输出（.bat 会被 PowerShell 当作文档执行）。
- 校验脚本 `scripts/validate_data.py` 是全库数据质量闸门：字段/标签/计数/字典覆盖率一道不过即整体失败；扩充前先按 §6.2 第 5 步更新其内置常量。
